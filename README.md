# EasyCustomItems
A Figura script that takes out all the scripting of making a custom item.

All you need to do is drop this file into your avatar folder!

In your avatar folder create a new block bench model filed as **items** (or download the example and slap it in your folder).

What is usually a root in most avatars should instead be **Item** (caps is important.)

in there, you make group underneath the Item group. Name it to whatever the item id of the minecraft item you will be making a custom item for.
Ensure it is lowercase and without the minecraft part but has the colon!
Ex. :crossbow, :bow, :spyglass

Once that is done you make on more group under that group. This one you simply name it the name of your item.
Custom names work as well.
Ex. Spyglass or [ Firearm ] ⟡Magnetite⟡

**HIGHLY RECOMMEND CHECKING THE EXAMPLE BBMODEL TO SHOW THE STRUCTURE AS WELL AS A PLACE TO START**
**IT ONLY WORKS WHEN HOLDING ONE ITEM**
